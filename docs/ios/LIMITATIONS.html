PacketCircle iOS: Limitations

PacketCircle 1.3.8 for iPhone and iPad is available on the App Store.

PacketCircle iOS favors responsiveness on phone. There is no hard-coded maximum PCAP file size, but memory, CPU, and a few feature caps set real expectations.

What to expect (quick guidance)

SituationComfortable on iPhonePossible but tight
PCAP / PCAPNG size~50–200 MBLarger files may feel slow or get memory-killed on older devices
Packet countHundreds of thousandsMillions — analysis streams, but decode/follow get heavy
Unique conversations (pairs)Hundreds → low thousandsVery large pair sets grow RAM
Circle Top N10 / 25 / 50Only top N pairs are drawn; Talkers lists all analyzed pairs
Hosts on the ringUp to 64 stable slotsExtra hosts may not get a permanent slot (Hosts mode)
Services layoutSame Top‑N pairsHost→service edges only; use legend filters if busy

Rule of thumb: Circle / Gauges / Talkers scale with how many unique pairs you have, not only with file size.

Open / analyze

Opening a capture streams frames from disk and keeps aggregates only (pairs, ports, protocols, TCP quality) — not every payload.

  • File size / packet count: soft limits (I/O + CPU)
  • Memory grows with unique conversations and TCP flows
  • Payloads are discarded after classification during analyze

Demo Mode

Loads every frame + payload into memory and replays ~60 seconds in a loop. Prefer a small demo file. Use Open Capture for real / large files.

Data scope & heuristics

  • Conversation vs Sockets focus changes TCP health aggregation
  • Client/server without SYN uses a well-known-port heuristic
  • TCP health is a native estimate — not Wireshark tcp.analysis

Formats & capture reality

  • PCAP and PCAPNG supported
  • No live capture on device
  • Truncated trailing frames tolerated (partial analysis)

Practical recommendations

  1. Prefer filtered captures for Decode / Follow TCP Stream.
  2. Keep opens in the ~50–200 MB comfort zone when possible.
  3. Lower Top N, switch Hosts ↔ Services, or filter protocols if the circle feels crowded.
  4. Raise Follow budget only when needed.
  5. Use Sockets focus to isolate a slow service on a shared IP pair.
  6. For huge captures: overview on phone, deep decode on laptop / Wireshark.
