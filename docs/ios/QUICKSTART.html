PacketCircle iOS: Quickstart

Offline PCAP/PCAPNG analyzer: Hosts ring or Services map, Gauges quality triage, session health, decode, and Follow TCP Stream.

Screenshots

Requirements

  • iOS 17+
  • Offline PCAP/PCAPNG only — no live capture

Steps

  1. Open Capture (or Demo Mode / guided tour) — full analyze; status bar shows file · packets · pairs
  2. Explore — Circle (Hosts / Services; Protocol or Quality), Gauges (degraded list + quality timeline), Talkers (all pairs; Circle keeps Top‑N), Decode
  3. Replay — tap status bar for original timing
  4. Session details — bi-dir summary; ports when a socket is selected; TCP health, exchange, app / TLS / ICMP previews
  5. Follow TCP Stream — client red / server blue; budget in Options
